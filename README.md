# MangaCarta Sources

Community-maintained sources for **MangaCarta**, a reader app for iPhone and iPad.

MangaCarta comes with no built-in content. To read from an online source, you add
this repository in the app and install the sources you want. Sources are small
scripts that tell the app how to reach a site; they run inside the app's sandbox and
can only contact the sites they declare.

> **MangaCarta does not provide or host any content, and neither does this
> repository.** Sources only connect the app to third-party sites. You are responsible
> for what you choose to install and read.

## Installation

1. Open **MangaCarta** and go to **Settings → Repositories**.
2. Tap **Add repository** and enter:

   ```
   https://proxy-link.github.io/mangacarta-sources/index.json
   ```

3. Open the repository and install the sources you want.

Installed sources are offered updates when this repository publishes a new version;
nothing changes on your device until you accept it.

## Status

The index offers MangaDex and WeebCentral. Site layouts and access requirements can change; report a source that stops working.

## Reporting a problem

Open an issue describing the source, what you tried, and what happened. Rights-holders
requesting the removal of a source can also open an issue; requests are honoured.
